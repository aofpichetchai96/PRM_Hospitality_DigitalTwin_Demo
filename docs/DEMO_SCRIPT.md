# PRM Hospitality Digital Twin — Demo Script

Demo เล่าเป็น **7 ฉาก** ใน PROPERTY EXPLORER (เมนูซ้าย ส่วนล่าง) กดแล้วแสดงทันที ไม่มีปุ่มชมเดโมหรือ Tour อัตโนมัติ
เมนู WORKSPACE ด้านบน (Executive overview · Digital Twin · IOC operations · Energy Lab · AI Assistant) ยังเปิดหน้าเดิมได้ตามต้องการ
เปลี่ยนฉากด้วยเมนู ด้วยคีย์ `1`–`7` หรือ `←` / `→` (ใช้กับ Wireless clicker ได้) · ใช้เวลาเล่าประมาณ 8–10 นาที
ทุกตัวเลขเป็นข้อมูลจำลอง พูดย้ำเสมอว่า "ไม่เชื่อมต่อระบบจริง" และใช้รูปประโยค "ระบบจริงจะ…"

## ก่อนเริ่ม (5 นาทีก่อนลูกค้าเข้าห้อง)

1. เปิด `npm start` แล้วเข้า `http://localhost:3000` (ไม่ต้องมีเน็ต)
2. Windows Graphics → ตั้ง browser เป็น **High performance** (ใช้ RTX 4060) — ดู `README.md`
3. กด `R` ให้ทุกอย่างกลับค่าเริ่มต้น → ต้องเห็น KPI **84% · 2,616 kW · 27,840 · Cases 3**
4. ถ้าต่อโปรเจคเตอร์: กด `P` ดูว่าภาพชัด (ใน Presentation ยังกด `1`–`7` เปลี่ยนฉากได้) แล้วกด `P` อีกครั้งเพื่อออก
5. เครื่องช้า / ภาพกระตุก: ตอนนี้ปุ่ม `?` (หน้าช่วยเหลือ: คุณภาพภาพ 3D) ถูกซ่อนไว้ — ตั้ง Windows Graphics ให้ใช้ RTX 4060 ก่อนเริ่ม

## หลังลูกค้าลองเล่น

- กด `R` (Reset Demo) — ทุกอย่างกลับค่าเริ่มต้นใน 1 คลิก

## คีย์ลัด (ใช้กับ wireless clicker ได้)

| คีย์ | ผล |
|---|---|
| `1` – `7` | เปิดฉาก Overview / Guest Room / Public Area / Event Hall / Back of House / ICT / AI Assistant |
| `→` / `PageDown` · `←` / `PageUp` | ฉากถัดไป / ก่อนหน้า |
| `Shift+1` – `Shift+5` | จำลองเหตุการณ์: CT fan trip · CHWS สูง · Pump vibration · Water leak · Lobby หนาแน่น |
| `P` | Presentation mode |
| `R` | Reset Demo |
| `[` / `]` | ชั้นลง / ขึ้น |
| `Home` | กลับมุมกล้องเริ่มต้นของฉาก |
| `Esc` | ปิดหน้าต่าง → ปิดแปลน → ยกเลิกชั้นที่เลือก → ออกจาก Slice → ออกจาก Presentation |

## แผนสำรอง

- ภาพ 3D ดับ / หน้าขาว: กดปุ่ม **โหลดฉากใหม่** ที่ขึ้นแทนภาพ หรือรีเฟรชหน้า (ข้อมูลกลับค่าเริ่มต้น)
- เครื่องหน่วง: หน้าช่วยเหลือ (ลดคุณภาพภาพ 3D) ถูกซ่อนไว้ — รีเฟรชหน้า หรือปิดโปรแกรมอื่นที่ใช้ GPU
- ทำงานได้โดยไม่มีอินเทอร์เน็ต — ไม่ต้องต่อ Wi-Fi ของสถานที่
