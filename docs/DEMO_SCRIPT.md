# PRM Hospitality Digital Twin — Demo Script (MVP)

บทพูดและลำดับการกดสำหรับ Demo ชุด MVP (Guided Demo 4 ขั้น) ใช้เวลาประมาณ 6–8 นาที
ทุกตัวเลขเป็นข้อมูลจำลอง — พูดย้ำเสมอว่า "ไม่เชื่อมต่อระบบจริง"

## ก่อนเริ่ม (5 นาทีก่อนลูกค้าเข้าห้อง)

1. เปิด `npm start` แล้วเข้า `http://localhost:3000` (ไม่ต้องมีเน็ต)
2. Windows Graphics → ตั้ง browser เป็น **High performance** (ใช้ RTX 4060) — ดู `README.md`
3. กด `R` ให้ทุกอย่างกลับค่าเริ่มต้น → ต้องเห็น KPI **84% · 2,616 kW · 27,840 · 3**
4. ถ้าต่อโปรเจคเตอร์: กด `P` ดูว่าภาพชัด แล้วกด `P` อีกครั้งเพื่อออก
5. เครื่องช้า / ภาพกระตุก: ปุ่ม `?` → คุณภาพภาพ 3D → กลาง หรือ ต่ำ

## หลังลูกค้าลองเล่น

- กด `R` (Reset Demo) — ทุกอย่างกลับค่าเริ่มต้นใน 1 คลิก
- ถ้าลูกค้าถามเรื่องที่ยังไม่มีใน MVP (IOC, CCTV, AI chat เต็ม, Floor plan) → "อยู่ในเฟสถัดไปของ Demo"

## คีย์ลัด (ใช้กับ wireless clicker ได้)

| คีย์ | ผล |
|---|---|
| `→` / `PageDown` | ขั้นถัดไป |
| `←` / `PageUp` | ขั้นก่อนหน้า |
| `P` | Presentation mode |
| `R` | Reset Demo |
| `[` / `]` | ชั้นลง / ขึ้น |
| `Home` | กลับมุมกล้องเริ่มต้นของหน้า |
| `Esc` | ปิดหน้าต่าง → ยกเลิกชั้นที่เลือก → ออกจาก Slice → ปิด Demo → ออกจาก Presentation |

## แผนสำรอง

- ภาพ 3D ดับ / หน้าขาว: กดปุ่ม **โหลดฉากใหม่** ที่ขึ้นแทนภาพ หรือรีเฟรชหน้า (ข้อมูลกลับค่าเริ่มต้น)
- เครื่องหน่วง: ลดคุณภาพภาพ 3D ในหน้าช่วยเหลือ (`?`)
- ทำงานได้โดยไม่มีอินเทอร์เน็ต — ไม่ต้องต่อ Wi-Fi ของสถานที่
