# Demo Checklist — ก่อนออกงานทุกครั้ง

ใช้คู่กับ [`DEMO_SCRIPT.md`](DEMO_SCRIPT.md) (บทพูด) · ✅ = ทำแล้วในรอบนี้

## วันก่อนงาน (ที่ออฟฟิศ มีเน็ต)

- [ ] `git pull` แล้ว `npm ci && npm run build` (ต้องมีเน็ตเพื่อโหลดฟอนต์)
- [ ] `npm test` และ `npm run test:e2e` ผ่านทั้งหมด (smoke test ตรวจว่าไม่มี request ออกนอกเครื่องด้วย)
- [ ] Windows Graphics: Edge / Chrome = **High performance** (RTX 4060) — ดู `README.md`
- [ ] `npm run benchmark` → ชื่อ GPU เป็น **NVIDIA GeForce RTX 4060** และ **PASS** ทั้ง 2 ขนาดจอ
- [ ] ซ้อมตาม `DEMO_SCRIPT.md` จบ 1 รอบ (9–12 นาที)

## ที่สถานที่ (30 นาทีก่อนเริ่ม)

- [ ] เสียบสายชาร์จ · ปิดการแจ้งเตือน Windows (Focus assist) · ปิดโปรแกรมอื่นที่ใช้ GPU
- [ ] `npm start` (หรือ `pm2 start ecosystem.config.js`) แล้วเปิด `http://localhost:3000` — **ไม่ต้องต่อ Wi-Fi ของสถานที่**
- [ ] ต่อจอนอก / โปรเจคเตอร์ → ตั้งเป็น Extend หรือ Duplicate ที่ 1920×1080 → ลาก browser ไปจอนั้น กด `F11` เต็มจอ
- [ ] กด `P` (Presentation) ดูว่าตัวอักษรอ่านออกจากท้ายห้อง แล้วกด `P` ออก
- [ ] Wireless clicker: ปุ่มถัดไป / ย้อนกลับ ต้องเลื่อน Guided Demo ได้ (ส่ง `→` / `PageDown`) — ถ้าปุ่มส่ง `Esc` / `F5` / `.` ให้ใช้เฉพาะปุ่มเลื่อน
- [ ] งานบูธ: `?` → เปิด **Attract mode** แล้วปล่อยไว้ 2 นาที → Demo ต้องเล่นวนเอง และแตะแล้วหยุด

## 5 นาทีก่อนลูกค้าเข้าห้อง

- [ ] กด `R` (Reset Demo) → KPI ต้องเป็น **84 % · 2,616 kW · 27,840 · 3**
- [ ] อยู่ที่หน้า Overview (พลบค่ำ อาคารหมุนช้าๆ)
